# Market Intelligence Dashboard (v32)

Streamlit dashboard for market, macro, and sector analysis.

## Deploy on Streamlit Community Cloud
- Repository branch: `main`
- Main file path: `app.py`
- Dependencies: `requirements.txt`
- Streamlit theme: `.streamlit/config.toml`

The app retrieves market data from Yahoo Finance through `yfinance`, so the deployed app needs outbound internet access.
